# Printable Calendar Maker — free demo

Try it in your browser: https://doddsy1967.github.io/printable-calendar-maker-demo/

This is the free demo of Printable Calendar Maker by SoloStack Creations. Everything can be clicked with the sample calendars. Nothing you make is saved, and printing is in the full app.

Full app: https://solostackcreations.etsy.com

The demo is one HTML file with no tracking and no network requests. All rights reserved; this demo is not open source.
